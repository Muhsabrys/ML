# ML Study App 🤖

A comprehensive mobile application for studying Machine Learning concepts, built with React Native and Expo.

## Features ✨

- **8 ML Topics**: From Introduction to ML to Model Evaluation
- **Interactive Learning**: Detailed explanations with examples and formulas
- **Quiz System**: Test your knowledge with multiple-choice questions
- **Progress Tracking**: Track your quiz performance
- **Clean UI**: Modern, intuitive interface for easy navigation
- **Cross-Platform**: Works on iOS, Android, and Web

## Topics Covered 📚

1. **Introduction to Machine Learning** - Fundamentals and types of learning
2. **Linear Regression** - Predicting continuous values
3. **Logistic Regression** - Classification algorithms
4. **Neural Networks** - Deep learning basics
5. **Decision Trees** - Tree-based models
6. **K-Means Clustering** - Unsupervised learning
7. **Support Vector Machines** - Powerful classification
8. **Model Evaluation** - Metrics and techniques

## Prerequisites 📋

- Node.js (v14 or higher)
- npm or yarn
- Expo Go app (for mobile testing)

## Installation 🚀

1. Clone the repository:
```bash
git clone https://github.com/Muhsabrys/ML.git
cd ML
```

2. Install dependencies:
```bash
npm install
```

## Running the App 🏃

### Start the development server:
```bash
npm start
```

### Run on specific platform:
```bash
# iOS (requires macOS)
npm run ios

# Android
npm run android

# Web
npm run web
```

### Using Expo Go:
1. Install Expo Go on your mobile device
2. Run `npm start`
3. Scan the QR code with your device
4. The app will open in Expo Go
